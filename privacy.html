Privacy Policy for SCE Drive Sync

Last updated: September 22, 2026

SCE Drive Sync is a private utility used by its developer to manage files associated with the Semitic Cognate Explorer project through Google Drive.

Google user data accessed

The application may access Google Drive file metadata and file contents only when necessary to store, retrieve, synchronize, or process project files.

How Google user data is used

Google Drive data is used solely for project file storage, retrieval, synchronization, and related file-processing workflows.

Storage

OAuth credentials may be stored locally and securely to permit continued authorized access. Project files may be downloaded temporarily for processing and may later be uploaded back to Google Drive.

Sharing

Google user data is not sold, rented, or shared with third parties for advertising, marketing, or unrelated purposes.

Data retention

Locally downloaded project files are retained only as long as reasonably necessary for project processing or synchronization. Google Drive remains the intended long-term storage location for project files.

Revoking access

Access may be revoked at any time through the Google Account permissions settings. Revoking access prevents the application from making further authorized Google Drive API requests.
